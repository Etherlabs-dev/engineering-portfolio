## Contra case study card

### Headline

Built a version-safe static creative studio from strategy handoff to reviewer-approved placement package

### Description

Static Creative Studio turns approved strategy, exact copy, safe claims, brand rules, and synthetic assets into reviewable ad versions. Feedback is attached to normalized regions on one exact artifact; corrections create child versions instead of overwriting history. A separate reviewer role controls approval, and the final action creates an idempotent local manifest with `published: false`.

### Skills

Product architecture, React, TypeScript, FastAPI, Python, SQLite, API design, authorization, optimistic concurrency, deterministic evaluation, responsive product design, CI/CD.
